## 1. 规则标量热图：整格悬停与取值

复用 `imshow` / `matshow`，首先覆盖 `interpolation="nearest"`。
日常示例提供行列名称、可选格内数值和配套颜色范围/色条。

- [x] 整个可见格子能 hover/click；返回原始零基 row、column、scalar value 与格子数据范围。
- [x] 默认提示能显示行列和值；自定义回调可显示中文行列名、单位和格式（组件与真实页面均已验收）。
- [x] 同次绘制复用真实单元格几何；非方阵、upper/lower、显式/反向 extent 与反向轴一致。
- [x] mask/NaN 等缺失格不返回有效值；边界归属规则为后绘制格优先，相邻格选择稳定。
- [x] 内核复用面板裁剪、图例遮挡、CSS 缩放和 letterbox；多图目标独立，更新后元数据随当前帧刷新。
- [x] 提供真实 DOM 示例与浏览器验收，检查悬停、点击、更新、缩放和缺失格。

RGB(A) 图片、none/平滑插值、曲面网格、pcolormesh/hist2d 分箱语义与大矩阵索引优化另行推进。
其中 none 当前走 PNG 分支，不能在只有 nearest 通过时宣称已经支持。

## 2. 多系列分类对比：分组柱与堆叠柱

增加适合 MoonBit 的明确入口，统一柱宽、位置与基线的几何计算，复用普通柱的颜色、图例和命中。

- [x] 支持分类上的多系列分组与堆叠，覆盖纵向和横向；输入尺寸错误有明确检查。
- [x] 分组柱共享正确的组中心与组内间距；普通柱的默认行为保持可用。
- [x] 堆叠柱分别累计正负值；自动范围包含真实宽度、非零起点与累计终点。
- [x] 每个分段整块可命中；提示保留系列名、类别和该段原始值，累计终点不冒充该段数值。
- [x] 多图、隐藏/重建系列和数据替换后，图例与命中数据一致。
- [x] 提供分组、正负堆叠与横向示例，实际检查 SVG 和浏览器提示。

本轮不扩展成所有柱样式参数，100% 堆叠与瀑布图留为后续场景。

## 3. 真正环形图：透明环孔与正确扇区

复用饼图的分类、原值和占比，增加真实的内外半径几何；不使用覆盖底色的方式模拟环孔。

- [x] 明确环厚/内半径的合法范围；默认饼图调用继续可用。
- [x] 中心孔透明；SVG 几何、提示与命中使用同一环扇区。
- [x] 环内部可悬停/点击，孔内和外圆外不命中；覆盖边界、旋转、跨零角和完整单片圆环。
- [x] 提示包含分类、原始值和占比；零值切片、数据更新和多图行为与饼图一致。
- [x] 示例在有色背景上展示透明孔，真实鼠标验收环与孔，而不只检查 SVG 字符串。
