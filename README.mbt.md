# MoonBit K-Means 聚类算法实现

本项目使用 MoonBit 语言从零手搓了 K-Means 聚类算法，并包含完整的单元测试、数据读取、特征标准化以及结果可视化功能。项目旨在脱离 Python (NumPy/Pandas/Scikit-learn) 的成熟封装，深入理解算法的底层数学逻辑与工程实现。

## 项目结构

本项目采用标准的 MoonBit 包（Package）结构，职责划分清晰：

- **`kmeans.mbt`**：核心算法库（Library Package）。
  - 定义了 `Point` 数据结构。
  - 包含了所有的算法函数：平方距离计算、质心分配、质心更新、初始化（随机与 K-means++）、收敛判断、特征标准化以及核心的 `kmeans` 主循环。
  - 包含了基于 `mathplotlib` 的数据可视化逻辑。
- **`kmeans_test.mbt`**：黑盒测试（Blackbox Test）。
  - 包含所有核心函数的单元测试。作为独立于主包的外部测试文件，它严格验证了对外暴露的 `pub` 接口的正确性，并避开了对内部实现细节的依赖。
- **`cmd/main/main.mbt`**：可执行入口（Executable Package）。
  - 负责串联整个流程：读取 CSV 数据 -> 转换类型 -> 特征标准化 -> 调用 K-means -> 保存并导出可视化 SVG 图表。
- **`moon.pkg` / `moon.mod`**：项目与包的配置文件，声明了模块依赖（如 `MoonFrame`、`mathplotlib`、`moonbitlang/x/fs` 等）。

## 代码构思与核心逻辑

相比于直接调用现成的库，本实现在代码构思上处理了以下关键工程细节：

### 1. 数据结构设计
定义了 `pub(all) struct Point { coords : Array[Double] }`。采用动态数组存储坐标，使得算法可以**无缝支持任意维度（d维）**的数据，而不仅限于二维。

### 2. K-means 核心四步曲
- **初始化**：除了基础的随机初始化外，额外实现了 **K-means++ 策略**（D² 采样）。通过计算每个点到已有质心的最小平方距离作为权重，有效避免了初始质心扎堆的问题，显著提升了算法的收敛稳定性。
- **分配 (Assign)**：手写 `argmin` 逻辑。遍历所有质心，寻找平方欧氏距离最小的索引。为避免开根号带来的性能损耗，比较时直接使用**平方距离**。
- **更新 (Update)**：遍历簇内点，对每一维度求均值。专门处理了**“空簇” (Empty Cluster)** 异常，当某簇无点时，保留其旧质心，防止程序崩溃。
- **收敛判断**：计算新旧质心的总平方移动量（Shift Squared）。使用 `shift < tol * tol` 作为停止条件，避免了浮点数直接使用 `==` 比较的陷阱。

### 3. 数据预处理：特征标准化 (Z-score Standardization)
K-means 基于欧氏距离，对量纲极度敏感。在接入真实的 Iris 数据集后，实现了 `standardize` 函数。在聚类前将所有维度缩放至均值为 0、标准差为 1，防止方差较大的特征主导聚类结果。

### 4. 可视化输出
接入 `Lampese/mathplotlib`，将聚类后的数据按标签分组（聚合），为不同的簇分配不同颜色，并将最终质心以黑色点叠加，最终导出为矢量 SVG 图表。
